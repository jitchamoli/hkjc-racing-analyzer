# ML + Probability Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a prioritized fix list for the HKJC racing analyzer's ML, probability, and betting-recommendation pipeline, grounded in forensic evidence from the 71-race holdout and two parallel expert-lens reviews (probability + data science). Audit is read-only; fixes are a separate downstream plan. **Every fix in the produced list carries a mandatory validation gate (backtest regression + test suite) — the downstream fix-implementation plan will not ship any change that fails this gate.**

**Architecture:** Three stages — (1) forensic probes run single-threaded on the holdout and Apr 22, (2) two parallel subagents with different expert personas produce independent systematic findings, (3) main agent synthesizes strategic layer and consolidates into a fix list with severity × tractability prioritization.

**Tech Stack:** Python 3 (existing HKJC analyzer), SQLite (`tracking_data/horse_history.db`), XGBoost model (`models/hkjc_racing_model.pkl`), `scripts/backtest.py` for holdout metrics, Markdown for deliverables.

**Spec:** `docs/superpowers/specs/2026-04-23-ml-audit-design.md`
